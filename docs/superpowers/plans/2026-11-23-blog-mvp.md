# 部落格第一版（MVP）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 Astro 預設範本改成名為「川流不息」的文字為主個人部落格（首頁、文章頁、分類頁、關於我、404），並改寫 README。

**Architecture:** Astro 靜態網站。文章是 `src/content/posts/*.md`，用內容集合（`glob` loader＋zod schema）管理；共用的查詢與日期格式放 `src/lib/posts.ts`；所有頁面共用一個 `BaseLayout`（刊頭＋主欄＋側欄），樣式用一份全域 CSS 加元件內 `<style>`。

**Tech Stack:** Astro 7.4.13、TypeScript（strict）、純 CSS，Node 24。不加任何新套件。

**Spec:** `docs/superpowers/specs/2026-11-23-blog-mvp-design.md`

## Global Constraints

- 網站名稱：`川流不息`；作者：`Chuan`
- `<html lang="zh-Hant-TW">`
- 分類代碼與顯示名稱：`life` → `生活`（磚紅 `#b5482f`）、`hobby` → `興趣`（靛藍 `#2f6a8a`）
- 底色 `#fbfaf7`，文字 `#222`，分隔線 `#e4e1da`，次要文字 `#555`／`#aaa`
- 標題字型堆疊（明體）：`"Noto Serif TC", "PMingLiU", "MingLiU", serif`；內文（黑體）：`"Noto Sans TC", "Microsoft JhengHei", "PingFang TC", sans-serif`。不載入網路字型
- 日期格式 `YYYY.MM.DD`
- 禁止：圓角卡片＋陰影、膠囊形標籤、圓形頭像佔位；不引入 Tailwind 或任何 CSS 框架
- `draft: true` 的文章不得出現在任何列表，也不產生文章頁
- 個人 repo，commit 不帶 Jira 單號；在 `feat/blog-mvp` 分支上做，不直接 commit 到 `main`
- 驗證方式：`npm run build` 成功，並檢查 `dist/` 產出的 HTML（專案沒有測試框架，第一版不加）

## Review Focus

1. **時區造成日期差一天**：frontmatter `date: 2026-11-20` 會被解析成 UTC 午夜；用本地時區格式化在 UTC 以西會顯示成 11/19。`formatDate` 一律用 UTC getter（Task 1 驗證）。
2. **草稿外洩**：`draft: true` 的文章不能出現在首頁、分類頁，也不能有 `/posts/<slug>/`（Task 1 放一篇草稿，Task 3、4 驗證）。
3. **分類沒有文章**：`hobby` 目前可能沒有任何已發佈文章，分類頁要顯示「這個分類還沒有文章。」而不是空白（Task 4 驗證）。
4. **手機寬度**：寬度 ≤ 720px 時側欄移到主欄下方，頁面不出現水平捲軸（Task 2 驗證）。
5. **檔名當網址**：文章網址取自檔名；README 與範例文章說明要用英文小寫加連字號命名（如 `rainy-day-soup.md`），避免中文網址被編碼成一長串（Task 5 寫進 README）。

2. `feat: 建立川流不息部落格的頁面與版面` — 其餘所有程式與內容（Task 1–4）

執行期間逐任務 commit 沒關係，Task 7 再整理成上面兩顆。

### Task 1: 網站設定、內容集合與查詢函式

**Files:**
- Create: `src/consts.ts`, `src/content.config.ts`, `src/lib/posts.ts`, `src/content/posts/hello-world.md`, `src/content/posts/draft-example.md`

**Interfaces:**
- Produces:
  - `src/consts.ts`：`SITE_TITLE = '川流不息'`、`AUTHOR = 'Chuan'`、`SITE_DESCRIPTION = '記錄生活裡流過的日子。'`、`ABOUT_SHORT = '喜歡記錄生活的人，偶爾寫寫興趣和正在做的東西。'`、`CATEGORIES = { life: { label: '生活', color: '#b5482f' }, hobby: { label: '興趣', color: '#2f6a8a' } } as const`、`type CategoryKey = keyof typeof CATEGORIES`
  - `posts` 集合 schema：`title: string`、`date: Date`（`z.coerce.date()`）、`category: 'life' | 'hobby'`（用 `z.enum` 取 `CATEGORIES` 的 key）、`description?: string`、`draft: boolean`（預設 `false`）。loader：`glob({ pattern: '**/*.md', base: './src/content/posts' })`，`z` 從 `astro/zod` 匯入
  - `getPublishedPosts(category?: CategoryKey): Promise<CollectionEntry<'posts'>[]>` — 排除 `draft`，可依分類過濾，依 `date` 新到舊
  - `formatDate(date: Date): string` — 回傳 `YYYY.MM.DD`，用 `getUTCFullYear/Month/Date`

- [ ] **Step 2:** 建立範例文章 `hello-world.md`：`title: 第一篇：歡迎來到川流不息`、`date: 2026-11-23`、`category: life`、`description: 這是一篇示範文章，說明怎麼寫新文章。`，內文用中文說明檔案放哪、frontmatter 各欄位意思、`draft` 用法、檔名用英文小寫加連字號，並提醒寫第一篇真正的文章後刪掉這篇。
