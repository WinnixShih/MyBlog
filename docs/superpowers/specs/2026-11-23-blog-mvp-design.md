# 部落格第一版（MVP）設計

網站名稱：**川流不息**（使用者決定）

## 目的

把 Astro 預設範本改成一個能用的個人部落格，先求有、再求好。目前以分享生活為主，之後會加入興趣發展的紀錄與個人專案；更後面會加上後端，並搬到自己的網域。現在部署在 Vercel：https://my-blog-seven-sand.vercel.app

## 目標

- 能用 Markdown 寫文章，push 到 `main` 後網站就會更新
- 首頁列出文章，點進去可以閱讀
- 文章分「生活」、「興趣」兩類，可以只看某一類
- 有一頁「關於我」
- README 改寫成這個專案的說明，附上 Vercel 網址

## 不做（這一版）

- 專案（Projects）頁：等有專案要放時再加
- 照片相簿、圖片排版：目前以文字為主
- 字體細選：先用系統字型，之後再挑
- 深色模式、搜尋、留言、按讚、標籤：留言與按讚等後端上線再說
- 自訂網域與後端

## 反目標

- 看起來像 AI 套版：不用圓角卡片加陰影、膠囊形標籤、圓形頭像佔位
- 一開始就塞滿功能，導致之後改不動

## 做法選擇

| 做法 | 取捨 | 結果 |
|---|---|---|
| A. 從空專案自己搭精簡版 | 每個檔案都看得懂，好擴充；外觀要自己設計 | **採用** |
| B. 套 Astro 官方 blog 範本 | 最快有完整樣子；全英文、要大量刪改，難摸清 | 不採用 |
| C. 套社群主題（如 AstroPaper） | 功能最多；太重，之後改造與接後端都要先讀懂整套 | 不採用 |

使用者選 A，理由是要自己設計，並且由 Claude 協助做出來。

## 外觀（已選定：C1 筆記本）

- 淺米白底（約 `#fbfaf7`），深灰黑字
- 文章之間用細線分隔，不用卡片、不用陰影
- 分類用不同顏色的文字區分：生活＝磚紅、興趣＝靛藍
- 文章標題用襯線字（明體），內文用無襯線字（黑體）；字型先用系統字型堆疊，之後再細選
- 版面：主欄文章列表＋右側欄「關於我」（一張照片＋一兩句介紹）；手機寬度時側欄移到文章下方

```
川流不息                        生活 ／ 興趣 ／ 關於
─────────────────────────────────────────────────
生活　2026.11.20                │ [你的照片]
下雨天，在家煮了一鍋湯            │ 關於我
原本想出門的週末……               │ 喜歡煮飯、咖啡……
──────────────────────          │
興趣　2026.11.12                │
開始學手沖咖啡的第一個月          │
```

## 頁面

| 網址 | 內容 |
|---|---|
| `/` | 全部文章，新到舊 |
| `/posts/<slug>/` | 單篇文章 |
| `/category/life/`、`/category/hobby/` | 只列該分類的文章 |
| `/about/` | 關於我 |
| 404 | 找不到頁面 |

## 文章格式

文章放 `src/content/posts/*.md`，用 Astro 內容集合（Content Collections）管理，frontmatter：

```yaml
title: 下雨天，在家煮了一鍋湯
date: 2026-11-20
category: life        # life | hobby
description: 一句話摘要（選填，首頁沒填就不顯示）
draft: false          # true 時不會出現在網站上
```

分類用固定的英文代碼（`life`、`hobby`），網址與程式用代碼，畫面上顯示中文。之後要加分類時改一處設定即可。
